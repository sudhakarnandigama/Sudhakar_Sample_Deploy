# ADR-004: Expose DTOs, never JPA entities

- **Date:** 2026-08-21
- **Status:** Accepted

## Context

Entities contain lazy associations and persistence metadata that must not leak into JSON responses.

## Decision

Define request/response DTOs and map between DTOs and entities inside the service layer. Controllers accept and return DTOs only.

## Consequences

- API contract is decoupled from the database schema.
- Avoids lazy-loading serialization bugs.
- Input is validated at the boundary via Jakarta Bean Validation.
- Requires mapping code and DTO classes.
