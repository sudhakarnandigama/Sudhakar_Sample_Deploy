# ADR-008: API-key authentication for stock mutation endpoints

- **Date:** 2026-08-21
- **Status:** Accepted

## Context

Every endpoint is currently public (`GAP-AUTH-01`). Issue #6 requires protecting sensitive operations — stock changes in particular — while keeping public endpoints public.

## Decision

Use a static API key, passed in the `X-API-Key` header, to protect the two stock mutation endpoints: `PUT /api/books/{id}/stock` and `PATCH /api/books/{id}/stock/adjust`. The key value is read from `BOOKSTORE_API_KEY` (property `bookstore.api-key`) and grants a single `STOCK_MANAGER` scope. All other endpoints remain public. No user accounts, sessions, or per-user identities yet.

## Consequences

- Stock mutations require the key; a missing or invalid key gets 401 with the standard error envelope.
- Read endpoints (GET stock, GET stock history) and all author/book endpoints stay public.
- A single shared secret; the only role is the implicit `STOCK_MANAGER` scope.
- If the key is unset, stock mutations fail closed (401).
